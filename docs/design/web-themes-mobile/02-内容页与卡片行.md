# 02 内容页与卡片行——移动端收口

覆盖三件事：详情页移动 hero 提档（用户决策 2）、移动行张数断点 + 半张卡、
搜索浮层换皮；末尾列 billboard 的核对项（已达标，不动）。

## 1. 详情页移动 hero 提档为 Netflix 专属（用户决策 2）

**现状**：`globals.css:461-465` 移动断点下两主题共用 `--detail-hero-h: 22vh /
--detail-hero-min-h: 120px`（主设计 §5.5 修订②的字面取值）；Netflix 桌面在
`globals.css:2172-2176` 单独提到 58vh/340px。移动端 hero 只占屏幕上沿一小条，
与银玻璃观感无差别。

**设计**：netflix 覆盖组的移动断点补一条变量覆盖——

```css
@media (max-width: 767px) {
  html[data-theme="netflix"] {
    --detail-hero-h: 40vh;
    --detail-hero-min-h: 220px;
  }
}
```

- **不动 JSX**：spacer（`media-detail-view.tsx:339`）与 `.detail-ambient` 渐变
  起点同源取这两个变量，改一处全链路跟随；标题 / 内容层负边距上叠
  （`-mt-28`，`media-detail-view.tsx:345`）继续成立——hero 变高后标题落点更
  靠画面中下部，恰是 Netflix App 详情的构图。
- **按钮构图**：订阅追踪主按钮吃 `.btn-accent`（netflix 覆盖组已改白底黑字）、
  次按钮吃 `.btn-glass`（灰半透方角），移动端无需单独按钮组件——提档后大横幅
  上的白色主按钮自然就是 Netflix 版式。验收时若「已订阅」态钮在亮图上对比度
  不足，仅调该钮的 bg 透明度，不新增结构。
- **银玻璃不动**：22vh/120px 维持主设计修订②。
- PageNav 保留（移动端详情的返回 + 吸顶雾，§01 已把雾换黑）。

**验证**：375px 视口详情页 hero 约占屏幕 40%，标题与主按钮落在剧照上、滚动后
雾层为纯黑系。

## 2. 移动行张数断点 + 半张卡（⚑4）

**现状**：`components/media-row.tsx:73` 竖版海报卡宽固定 `max-md:w-[126px]`
（152/164 桌面档）。主设计 §7 断点表「500–767 每行 3 张、<500 2~3 张 + 半张
peek」无对应实现。NetflixRow 的移动常规行（`netflix/row.tsx:129-139`）、
发现页、库首页全部走 MediaRow，一处改全站跟随。

**设计**：

1. MediaRow 的 HScroller 挂稳定类 `m-row`（新增，常驻不分主题——银玻璃也挂，
  但 CSS 只在 netflix 作用域命中）。
2. netflix 覆盖组加一条：

```css
@media (max-width: 767px) {
  html[data-theme="netflix"] .m-row > div {
    width: clamp(100px, 30vw, 156px);
  }
}
```

   375px 视口 → 112px（≈3 张可见 + 半张 peek）；500px → 150px（≈3 张）；
   320px → 100px（≈2~3 张）——正好落进 §7 表两档。卡宽随屏变宽（126→156 上限）
   是有意的：Netflix App 的海报卡明显大于银玻璃的信息密集排版。
3. **半张卡 peek**：卡宽公式天然保证（视口宽 ÷ 卡宽非整数，尾卡必然探出半张），
   不做额外机制；`scroll-padding` 不需要（横滚容器自然滚动）。
4. 继续观看行的 16:9 横版卡（`netflix/row.tsx:121` `max-md:w-[168px]`）本档
   **不动**，375px 下 ≈2 张可见 + peek，与 App 节奏一致；验收时再定是否提宽。

**为什么用 CSS 一条规则而不是组件分支**：行卡尺寸是纯视觉参数，netflix 作用域
CSS 是本项目主题换肤的既有语言（40 处先例）；组件分支会迫使 MediaRow 认识主题，
违反「主题是唯一全局生效物」的框架约定（主设计 §3.2）。

## 3. 搜索浮层换 Netflix 皮（⚑5）

**现状**：`components/search-command.tsx:430` 面板用工具类任意值
`bg-[rgba(21,23,29,0.96)] rounded-2xl … backdrop-blur-2xl`——银玻璃深蓝灰半透
+ 大圆角 + 重模糊。移动端搜索入口在 MobileTopBar / PageNav 两处，弹出的都是它。

**设计**：globals.css netflix 覆盖组加（无层 CSS，特异性 0,2,0 压过工具类，
项目同型先例即 `.search-palette-panel` 动画规则也在无层）：

```css
html[data-theme="netflix"] .search-palette-panel {
  background: #181818;            /* Netflix 弹层实底（卡片面色） */
  border-color: rgba(255, 255, 255, 0.08);
  border-radius: 6px;             /* 弹窗档（§2.3） */
  backdrop-filter: none;          /* 纯色平铺，无玻璃 */
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.9);
}
```

面板内部的输入行、历史列表、分组标题全部吃 `--text-*` token，自动跟随；不逐个
改组件。遮罩 `search-palette-overlay` 若为半透色也一并核对为黑系。

## 5. 失败路径与安全网

- 行宽公式的极端屏（折叠屏 320~500px）：clamp 下限 100px 保证不小于触控目标的
  卡片点击区；上限 156px 保证 767px 档不超桌面节奏。
- 搜索浮层：netflix 规则只换面板容器，输入焦点 / 键盘避让（`max-md:max-h[…]
  --keyboard-inset`）全部保留，无回归面。
- 详情 hero 提档只改 CSS 变量，回退 = 删两条声明。
