# 01 外壳与导航——移动端换皮收口

覆盖四件事：TabBar 高度修复（bug）、MobileTopBar 换 Netflix 皮、PageNav 吸顶雾
变量化、theme-color / PWA 跟随主题。全部落在既有文件上，无新组件。

## 1. TabBar 高度修复（bug，先修）

**现状**：`components/netflix/tab-bar.tsx:71` 的 `h-[49px] … pb-[var(--safe-bottom)]`
——Tailwind preflight 全站 border-box，49px 是**总高**，安全区 padding 在其中
再扣。让位规则（`globals.css:2411`）却按 `calc(49px + var(--safe-bottom))` 让位，
两处口径不一致：iPhone 全面屏（safe-bottom≈34px）上页签内容区只剩 ~15px，
24px 图标溢出。

**设计**：一行改为 `h-[calc(49px+var(--safe-bottom))]`，`pb-[var(--safe-bottom)]`
保留（图标那一行落到安全区以下，这正是 Netflix App 底栏的层次）。`.nf-tabbar`
背景 `rgba(10,10,10,0.95)` 本就是 Netflix 黑系，不动。

**验证**：DevTools iPhone 15 视口（safe-bottom=34）下四页签图标 + 10px 标签
完整显示、不被 Home 指示条压住。

## 2. MobileTopBar 换 Netflix 皮（用户决策 1）

**现状**：`components/app-shell.tsx:495-565` 的 MobileTopBar 在 Netflix 移动端
照常渲染（`app-shell.tsx:305-312`，有意保留承载 `setTopBarActions` 页面级控件
与搜索——activity / agent-conversation / discover / subscriptions 四个页面在用），
但三处仍是银玻璃：雾层色、品牌 logo、汉堡键 aria。

**设计**（外壳内一处分支，页面无感）：

1. **雾层**：globals.css 的 netflix 覆盖组加一条
   `html[data-theme="netflix"] .mobile-topbar`——渐变三停靠点换纯黑系
   `rgba(0,0,0,…)`（0.86/0.6/0 → 0.8/0.55/0，Netflix 画布是纯黑，蓝黑雾在其上
   会读出色偏），`backdrop-filter` 与 mask 原样保留（纯黑底上 blur 无感，保留
   是为了雾下滚过的海报墙仍被压糊——这正是雾的职责）。
2. **品牌**：`MobileTopBar` 增加 `variant` 入参（或内部 `useTheme()`），
   Netflix 分支用 `MovieclawWordmark`（红色内联 SVG，`components/netflix/brand.tsx`，
   零网络请求）替代 `Image` rotor 图；视觉高度对齐现值 `h-7`、44px 命中区按钮
   结构不变。银玻璃分支原样。
3. **aria**：Netflix 下汉堡键 `aria-label` 由「打开侧边栏」改「打开我的面板」
   （该键在 Netflix 下开的是 NetflixMySheet，`app-shell.tsx:231-234`）。

**为什么不是退役**（用户已拍板保留，此处记录理由供追溯）：退役需为 4+ 个页面的
页面级控件与移动搜索另找安置点，逐页改造且伤可达性；Netflix App 三 tab 期
首页顶部同样有搜索入口浮在内容上，保留一条透明黑雾顶栏不违和。

## 3. PageNav 吸顶雾变量化 + Netflix 黑

**现状**：`components/page-nav.tsx:149-156` 雾层渐变是**内联 style** 写死的
`rgba(9,11,16,…)`（银玻璃蓝黑），CSS 压不过内联（主设计 §5.5 ⑨ visibility
教训同源）。移动端详情页滚动吸顶时顶部露银玻璃雾。

**设计**：

1. globals.css `:root` 新增 `--page-fog`（值 = 现内联的那条
   `linear-gradient(180deg, rgba(9,11,16,0.72), rgba(9,11,16,0.46) 46%, rgba(9,11,16,0))`）。
2. page-nav.tsx 内联 style 改为 `background: "var(--page-fog)"`（无 fallback
   必要——`:root` 定义与组件同文件树，不存在读不到的场景）。
3. netflix 覆盖组：`html[data-theme="netflix"] { --page-fog: linear-gradient(180deg,
   rgba(0,0,0,0.72), rgba(0,0,0,0.46) 46%, transparent) }`——只换色相，浓度档
   保留（雾的「压字不糊」手感是全站调过的，不因主题重调）。
4. PageNav 的汉堡键 aria（`page-nav.tsx:166`「打开侧边栏」）与 §2.3 同步修正。
   PageNav 自带搜索键（`page-nav.tsx:202-209`）不动。

`.mobile-topbar` 是纯 CSS 类不需要变量化（§2.1 直接覆盖）；`--page-fog` 单独
服务 PageNav 的内联雾。

## 4. theme-color 跟随主题（⚑3）

**现状**：`app/layout.tsx:76` `themeColor: "#0a0b10"` 固定银玻璃；运行时无任何
meta 更新；`app/manifest.ts` 也是静态 `#0a0b10`。

**设计**（两处，各一行级）：

1. **运行时**：`lib/ui-prefs.tsx` 里把 `data-theme` 写上 `<html>` 的那个 effect
   （`ui-prefs.tsx:99-103`）顺带把 `<meta name="theme-color">` 的 content 写为
   主题画布色（netflix→`#000`，silver→`#0a0b10`）——设置页实时预览切主题时
   浏览器 UI 框颜色即时跟随。**实现期实测补充（2026-09-13）**：Next 的路由
   元数据机制会在部分客户端导航后把 viewport 导出的静态 themeColor 写回
   `#0a0b10`，effect 的 `[effectiveTheme]` 依赖追不上——同一 effect 里挂
   MutationObserver 观察该 meta 的 content 属性，被改写即重新断言当前主题
   的画布色，覆盖一切改写来源。
2. **首帧**：`RESTORE_THEME_SCRIPT`（`app/layout.tsx:104`）在白名单命中
   `netflix` 时同步把 meta 改 `#000`，避免强刷后浏览器框先闪一段银玻璃色。
   meta 标签由 Next 的 viewport 导出注入，脚本执行时已在 DOM（`<head>` 同步
   解析）；找不到时静默跳过（脚本已有 try/catch 外壳）。
3. **manifest 不动**（⚑3 拍板）：安装过渡帧只出现一次，银玻璃底色可接受；
   动态 manifest 需 cookie 路由，过度设计。

## 5. 与现有代码的关系

| 复用 | 改动 |
|------|------|
| `MovieclawWordmark` / `MovieclawMark`（brand.tsx，纯内联 SVG） | MobileTopBar 字标分支 |
| netflix 覆盖组的「无层 CSS 压工具类」既有模式（globals.css 40 处先例） | `.mobile-topbar`、`--page-fog` 两条新规则 |
| `ui-prefs` 的 data-theme 同步 effect、`RESTORE_THEME_SCRIPT` 白名单 | 各加一行 meta 写入 |
| `setTopBarActions` / PageChrome 契约（`lib/page-chrome.tsx`） | **零改动**（换皮不碰契约） |
| 银玻璃主题全部路径 | **零改动**（所有新规则都在 `html[data-theme="netflix"]` 作用域内） |

## 6. 失败路径与安全网

- 主题来回切换：meta / data-theme / 字标分支都由同一个 theme 状态驱动，不存在
  半换皮态；回银玻璃即全部还原（netflix 规则整体失效）。
- 老后端（无 theme 字段）：`normalizeThemeId` 兜底 silver，meta 保持 `#0a0b10`，
  与现状一致。
- 脚本失败：`RESTORE_THEME_SCRIPT` 已有 try/catch，meta 不同步只影响浏览器框
  颜色，不影响功能。

## 7. 2026-09-14 修订：导航体系成页化

用户反馈 Netflix 移动端「业务交互不成体系、像个半成品」，本轮把残留的浮层/
玻璃交互收敛为成体系的路由导航（详见 web-themes.md §5.2 的同步修订）：

1. **底栏四页签**：发现 / 媒体库 / 订阅 / 我的。移除「首页」页签（`/` 由顶栏
   字标直达）；「订阅」按 `canSubscribe` 显隐；「我的」由开关面板改为路由
   Link。`/media/*` 详情子页的页签归属从「媒体库」改判「发现」（它本来就是
   发现来源的详情路由）。
2. **「我的」成页**：新增路由 `/my`（`components/netflix/my-page.tsx`），内容
   迁自 NetflixMySheet（用户头 / 新任务 / 我的订阅 / 活动 / 设置 / AI 会话 /
   切换账号 / 退出登录）。原右侧滑出面板与 `.nf-mysheet` CSS 退役；银玻璃
   主题直达 `/my` 时跳回 `/`（它的同等入口在抽屉侧栏）。
3. **设置 = 「我的」的二级页面**：`NetflixSettingsNav` 左端加返回键
   （`useBackNavigation("/my")`：优先消费真实站内来路，直达回落 `/my`），
   分区下拉保留；分区大图标头在 Netflix 移动端隐藏（globals.css
   `.settings-panel-head`，与下拉重复且占位）。
4. **顶栏去 ☰**：Netflix 移动端的 MobileTopBar 与 PageNav 都不再渲染汉堡键
   ——导航全在底栏页签，顶栏宽度让给页面级控件（发现页现在挂三个：电影/
   剧集 + 筛选 + 数据源）。`PageChrome.openDrawer` 契约保留，Netflix 分支
   改为跳 `/my`（兼容任何残留唤起点）。
5. **品牌加载动画主题分叉**：BrandLoader 双渲染（rotor 图 / 红色 M 字标
   SVG）+ CSS 显隐——组件保持无状态、服务端组件可用。
6. **详情页 hero 移动端补渐变**：`nf-hero-live` 标记类从「Netflix 桌面」放宽
   为「Netflix」（media-detail 移动端同样挂载），globals.css 把「左黑右图」
   mask 收窄为 ≥768px、新增移动端 `::after` 纵向渐隐档（顶部一抹暗护状态
   栏 + ~60vh 落纯黑）；library-item-detail 桌面补挂同一套滚动退场（此前
   该页在 Netflix 桌面完全没有渐变），spacer 改用 `--detail-hero-h` 变量、
   内容层补 `detail-content` 上移钩子。`detail-ambient--hero` 的 Netflix
   底色 #141414 改 #000（与手机页内 Hero 的 to-black 渐变终点同色，
   消除图/内容交界处的色差缝）。

## 8. 2026-09-15 修订：首页并入媒体库 + 设置分区列表页
