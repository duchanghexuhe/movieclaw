## 2. 关键故障场景与预期行为

| 场景 | 预期 |
|------|------|
| 全新部署（无媒体数据） | 媒体库页空态引导卡；Netflix hero（Billboard）不渲染（2026-09-15 起） |
| 老后端（无 ui.preferences.theme 字段） | 兜底 silver，全部银玻璃原样 |
| localStorage 偏好缓存被篡改（非 netflix 值） | 白名单不命中，silver 兜底，meta 不动 |
| 横屏（safe-left/right 生效） | 顶栏图标让开刘海；TabBar 高度公式含 safe-bottom 不受影响 |
| `prefers-reduced-motion` | 展开卡 / 面板动画退化为瞬时（既有规则，无新增动画则无新增面） |

## 3. 回归红线（发布三约束核对）

- 无依赖变更（纯前端 CSS/TSX）→ 不触发 runtime-version bump。
- 无数据库迁移 → 回退安全。
- 版本号不涉发版，本分支合并走常规 PR + CI（`pytest -m "not integration"` 与
  web 构建门禁）。

## 4. 2026-09-15 修订：首页并入媒体库 + 设置分区列表页

1. **首页退役**：`/` 在 Netflix 主题下 replace 到 `/library`；Billboard 以
   `NetflixLibraryHero` 挂在媒体库页行清单上方（`isHome` 氛围页判定同步扩展，
   画面从透明顶栏底下直出）；桌面顶栏删「首页」链接（五项变四项），双端字标
   直达 `/library`；底栏「媒体库」页签高亮含 `/`。
2. **设置成页**：`/settings`（Netflix 移动端）渲染分区列表页
   `NetflixSettingsIndex`（`settingsSectionGroupsFor` 按角色分组，glass-row 行），
   点行进 `/settings/[section]`；原「NetflixSettingsNav 标题旁的分区下拉浮层」
   退役（长清单高过视口且触屏滑不动）。返回链固定
   `/settings/[x] → /settings → /my`；「我的」页的设置行、底栏页签高亮
   （settings 归属「我的」）随之调整。银玻璃与 Netflix 桌面的 `/settings`
   照旧重定向首个分区。
3. 验收路径：我的 → 设置 → 任一分区 → 返回键回分区列表 → 返回键回「我的」；
   390 / 320 视口各过一遍（重点：分区列表整页可滚、无浮层）。
