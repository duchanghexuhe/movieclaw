# 03 验收——Netflix 主题移动端收口

环境：本机前后端 dev（隔离数据库配方见记忆 local-ui-dev-environment），
Chrome DevTools 移动视口 390 / 375 / 320 三档 + 真机 PWA 抽查（可选）。
主题切换入口：设置 → 外观 → 主题。

## 1. 端到端验收清单

### A. 外壳（§01）

| # | 步骤 | 预期 |
|---|------|------|
| A1 | Netflix 主题，375px 视口任意非详情页 | 顶部雾层为纯黑系（无蓝黑色偏），左上红色 MOVIECLAW 字标 |
| A2 | 同上，点汉堡键 | 打开「我的」面板；读屏 / aria-label 为「打开我的面板」 |
| A3 | 底部标签栏（safe-bottom=34 模拟全面屏） | 四页签图标 24px + 标签完整、不被 Home 指示条压住；内容行滚到底不被标签栏盖住 |
| A4 | 「我的」面板 | 用户信息 / 新任务 / 我的订阅 / 活动 / 设置 / AI 会话 / 切换账号 / 退出全可达；点任一项跳转后面板收起；Esc 关闭 |
| A5 | 详情页滚动 | PageNav 吸顶雾为纯黑系；返回键 / 标题 / 搜索键可达 |

## 2. 关键故障场景与预期行为

| 场景 | 预期 |
|------|------|
| 全新部署（无媒体数据） | 首页空态引导卡（不出现空行标题） |
| 老后端（无 ui.preferences.theme 字段） | 兜底 silver，全部银玻璃原样 |
| localStorage 偏好缓存被篡改（非 netflix 值） | 白名单不命中，silver 兜底，meta 不动 |
| 横屏（safe-left/right 生效） | 顶栏图标让开刘海；TabBar 高度公式含 safe-bottom 不受影响 |
| `prefers-reduced-motion` | 展开卡 / 面板动画退化为瞬时（既有规则，无新增动画则无新增面） |

## 3. 回归红线（发布三约束核对）

- 无依赖变更（纯前端 CSS/TSX）→ 不触发 runtime-version bump。
- 无数据库迁移 → 回退安全。
- 版本号不涉发版，本分支合并走常规 PR + CI（`pytest -m "not integration"` 与
  web 构建门禁）。
